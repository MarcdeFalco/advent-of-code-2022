# Advent of Code 2022

Solutions pour l'Advent of Code 2022 (https://adventofcode.com/2022).
Les énoncés et les entrées ne sont pas inclus, à la demande du créateur d'Advent of Code : chaque solution lit son entrée dans un fichier `input.txt` (ou le nom indiqué) à récupérer sur le site.

Chaque dossier `dayNN` contient une solution `solution.py` (et parfois
`solution.c`, `solution.ml`) qui affiche les réponses des deux parties ; la
méthode est résumée en tête de fichier. Quelques variantes
(`solution_une_ligne.py`, `visualisation.py`, ...) sont décrites de la même
façon. Les jours 1 et 2 lisent un fichier `input` ; les versions C des jours 2
et 4 lisent l'entrée standard (`./a.out < input`).

Les solutions sont écrites en `Python`, `C` et `OCaml`.

En général :

* le code `C` est assez direct et rapide
* le code `OCaml` est plutôt fonctionnel pur
* le code `Python` est là pour pousser le langage dans ses retranchements
